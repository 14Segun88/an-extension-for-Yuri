# Chrome Extension: Todoist Overdue Notifier (Архивный модуль)

Модуль браузерного расширения Chrome (Manifest V3) для интеграции с Todoist и уведомления ответственных о просроченных задачах.

---

## 📌 Описание компонента

- **Назначение**: фоновое сканирование Todoist REST API и отправка email-уведомлений через локальный backend (`http://localhost:8787/v3/smtp/email`).
- **Связь с основной платформой**: использует общий локальный backend-сервер `todoist-overdue-ext/backend/server.js`, который также обслуживает основную B2B-рассылку ЧЗ «Механика».
- **Файлы расширения**:
  - `manifest.json` — манифест Chrome MV3.
  - `background.js` — Service Worker для периодического сканирования.
  - `popup/` — всплывающее окно быстрого статуса.
  - `options/` — страница настроек API-токенов.
  - `lib/` — библиотеки интеграции (Todoist, Brevo-совместимый транспорт, хранилище, логгер).

# Backend Сервис: Диспетчер рассылки, LM Studio AI и CRM API

Локальный backend-сервис на Node.js для обслуживания платформы B2B-рассылки ЧЗ «Механика» и веб-дашборда (`http://localhost:8787/dashboard`).

---

## 🛠️ Возможности сервиса

1. **Центр управления рассылкой и Двухрежимный Диспетчер (Dual-Mode)**:
   - **Авто-пилот**: фоновый таймер (каждые 30 сек) анализирует календарные интервалы воронки (+3–5 дн, +4–5 дн, +4–7 дн, +7 дн) и запускает дожимы автоматически.
   - **Ручной режим**: запуск любого из касаний 2..5 по кнопке оператора для конкретной партии, режим отладки `⏱️ 0 дн ожидания`.
   - **Защита лидов**: заводы, ответившие в CRM (например, АО «МСЗ» ТВЭЛ Росатом), автоматически блокируются от всех follow-up касаний.
   - Подключение по защищенному протоколу SSL через порт `465` (Яндекс 360 SMTP).
   - Антиспам Rate-Limiter: строгая пауза **35 секунд** между письмами с таймером обратного отсчета.
   - Скрытая копия (BCC) на контрольные адреса руководства (`pdu@mehan59.ru`, `krantehpto@list.ru`).
   - Запись логов с Message-ID почтового сервера в `campaign_emails/dispatch_log.json`.

2. **Интеграция с локальной нейросетью LM Studio (Qwen 2.5)**:
   - Автоматический скоринг ICP и болей цеха по промпредприятиям.
   - Генерация персональных цепочек 5 касаний под раскрой листовой стали.
   - AI-Супервизор воронки для диагностики застрявших сделок.

3. **Сетевой опрос DNS MX**:
   - Прямой асинхронный опрос MX-записей доменов предприятий с замером миллисекундной задержки шлюза.

4. **Многопартийная CRM-воронка (Multi-Batch Accumulation)**:
   - Сквозное накопление базы предприятий (без затирания предыдущих запусков).
   - Пагинация порциями строго по 15 заводов с кнопкой «Далее».

---

## 🚀 Запуск сервиса

```bash
# 1. Установка зависимостей (если запускается впервые)
npm install

# 2. Настройка переменных в .env (скопируйте из .env.example)
cp .env.example .env

# 3. Запуск сервера
node server.js
```

Сервер доступен по адресам:
- Дашборд: `http://localhost:8787/dashboard`
- API очередей авто-пилота: `http://localhost:8787/api/autopilot/status`
- API данных кампании: `http://localhost:8787/api/campaign/data`
- Проверка SMTP: `POST http://localhost:8787/api/smtp/verify`

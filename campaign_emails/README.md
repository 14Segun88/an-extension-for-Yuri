# Каталог данных кампаний: База, Логи и Шаблоны писем

В этой директории хранятся рабочие данные рассылок, логов отправок и сформированных лидов ЧЗ «Механика».

---

## 📁 Структура файлов

| Файл | Описание | Актуальный статус |
|---|---|---|
| Файл | Описание | Актуальный статус |
|---|---|---|
| **`campaign_dataset.json`** | Единая база предприятий всех партий со скорингом, болями цеха и сформированными HTML-письмами | **60 заводов** (накопленные 4 партии) |
| **`followup1_dataset.json`** | Касание 2 (Follow-up №1, День 3–5): выгода 70% площади цеха, адаптация под лазер | **55 заводов** (все ответившие лиды исключены) |
| **`followup2_dataset.json`** | Касание 3 (Follow-up №2, День 7–10): обращение к Главному инженеру, защита листа | **55 заводов** (все ответившие лиды исключены) |
| **`followup3_dataset.json`** | Касание 4 (Follow-up №3, День 14): видео-кейс и 10-мин экспресс-созвон с инженером | **55 заводов** (все ответившие лиды исключены) |
| **`followup4_dataset.json`** | Касание 5 (Финал, День 21): бронь производственного слота ЧЗМ на текущий квартал | **55 заводов** (все ответившие лиды исключены) |
| **`autopilot_config.json`** | Конфигурация двухрежимного диспетчера (режим, интервалы, тест-флаг) | `{"mode": "auto", "enabled": true, "testModeImmediate": false}` |
| **`dispatch_log.json`** | Журнал отправленных писем через Яндекс 360 SMTP с Message-ID и статусами | Актуальный журнал отправок (SMTP 250 OK) |
| **`leads.json`** | Реестр лидов, автоматически захваченных IMAP-монитором входящей почты | **5 лидов** (Росатом МСЗ, ММЗ Мытищи, ООО РОДНОК, Коломенский завод ТМХ) |
| **`bounced_emails.json`** | Реестр адресов с системными ошибками недоставки (NDR/Bounce) | Исключаются из рассылки для защиты репутации домена |
| **`preview_15_emails.html`** | Автономная витрина для предпросмотра сгенерированных писем | Доступен для открытия в любом браузере |
| **`email_01_kmz1.ru.txt` … `email_15_zenit-kmz.ru.txt`** | Текстовые дампы писем первой партии для быстрого копирования | Сохраняются для архива |
| **`campaign_dataset_backup_*.json`** | Автоматические резервные копии базы при загрузке новых партий | Страховочные копии |

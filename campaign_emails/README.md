# Каталог данных кампаний: База, Логи и Шаблоны писем

В этой директории хранятся рабочие данные рассылок, логов отправок и сформированных лидов ЧЗ «Механика».

---

## 📁 Структура файлов

| Файл | Описание | Актуальный статус |
|---|---|---|
| **`campaign_dataset.json`** | Единая база предприятий всех прогонов со скорингом, болями цеха и сформированными HTML-письмами | **30 заводов** (Партия 1 от 14.10 + Партия 2 от 18.10) |
| **`followup1_dataset.json`** | Касание 2 (Follow-up №1, День 3–5): выгода 70% площади цеха, адаптация под лазер | **29 заводов** (завод №5 ТВЭЛ Росатом исключен) |
| **`followup2_dataset.json`** | Касание 3 (Follow-up №2, День 7–10): обращение к Главному инженеру, защита листа | **29 заводов** |
| **`followup3_dataset.json`** | Касание 4 (Follow-up №3, День 14): видео-кейс и 10-мин экспресс-созвон с инженером | **29 заводов** |
| **`followup4_dataset.json`** | Касание 5 (Финал, День 21): бронь производственного слота ЧЗМ на текущий квартал | **29 заводов** |
| **`autopilot_config.json`** | Конфигурация двухрежимного диспетчера (режим, интервалы, тест-флаг) | `{"mode": "auto", "enabled": true, "testModeImmediate": false}` |
| **`dispatch_log.json`** | Журнал отправленных писем через Яндекс 360 SMTP с Message-ID и статусами | **44 записи** (30 первичных + 14 Follow-up №1, SMTP 250 OK) |
| **`leads.json`** | База лидов, зафиксированных через форму квалификации или полученных ответов | Зафиксирован лид: **АО «МСЗ» (ТВЭЛ Росатом)** |
| **`preview_15_emails.html`** | Автономная витрина для предпросмотра сгенерированных писем | Доступен для открытия в любом браузере |
| **`email_01_kmz1.ru.txt` … `email_15_zenit-kmz.ru.txt`** | Текстовые дампы писем первой партии для быстрого копирования | Сохраняются для архива |
| **`campaign_dataset_backup_*.json`** | Автоматические резервные копии базы при загрузке новых партий | Страховочные копии |
